# Подсказки кнопок под Switch

## Зачем

Игра показывает иконки и тексты кнопок Xbox 360: цветные A/B/X/Y, LT/RT/LB/RB, логотип Xbox, «Press the START
Button», «Press START to Skip», «Press the BACK button». На Switch это должны быть кнопки Switch.
Ориентир — masseffect-nx (там заменили тексты в памяти; иконки там векторные и их оставили). Здесь иконки —
обычная текстура, поэтому их тоже перерисовываем.

## Что делаем

- Атлас иконок `bt_icon_360_bt_icon_D5` (128×192, DXT5, 4×6 ячеек по 32×32, Xenos tiled, 8in16) в
  `2D/COMMON.2DP`, `2D/COMMON_DE.2DP`, `2D/COMMON_FR.2DP` по смещению 0x60000, 32 КБ: свой атлас в той же сетке.
  Ячейки (номер = `<ICON=n>` в текстах): 0 A, 1 B, 2 X, 3 Y, 4 LT→ZL, 5 RT→ZR, 6 LB→L, 7 RB→R, 8 левый стик,
  9 правый стик, 10/11 нажатие стиков, 12 BACK→−, 13 START→+, 14 крестовина, 15 Guide→HOME, 16–19 направления
  крестовины, 20/21 левый стик по горизонтали/вертикали, 22 эмблема игры (не трогаем).
- Подписи меню навыков `skill_menu_x360_L1/L2/R1/R2` (DXT3, `2D/SYSTEM_MENU.2DP`, 0x74000…0x80000 по 16 КБ):
  «L», «ZL», «R», «ZR» в том же рукописном стиле.
- Тексты (EN/FR/DE, JA если есть): START → «+», BACK → «−» в `TEXT/NIER_TEXT.TXD` и
  `TEXT/INFO_TEXT/INFOWINDOW.*.INW`; правки той же длины, пробелы ставятся так, чтобы выравнивание не съехало.
- Буквы A/B/X/Y не переставляем: SDK переводит кнопки по буквам (`input_xbox_layout = false`), START = «+»,
  BACK = «−».

## Как

Вариант А (выбран): правка данных в момент чтения файла.
- SDK: фильтр чтения — функция, которую `XFile::ReadInternal` вызывает после успешного чтения с путём файла
  гостя, смещением и прочитанными байтами.
- Приложение (`app/src/nier_switch_prompts.cpp`): при первом чтении `layer1.cpk`/`layer2.cpk` читает оглавление
  CPK (@UTF), находит нужные файлы, проверяет XXH3 исходных байт каждого заменяемого куска и, если совпало,
  накладывает свои байты на пересечение каждого чтения с куском. Несовпадение — кусок не трогаем, одна строка в
  лог. Cvar `nier_switch_prompts` (по умолчанию включено).
- Иконки рисует наш скрипт `tools/switch_prompts/draw.py` (PIL, без чужих изображений и логотипов Nintendo),
  кодирует в DXT5/DXT3 с тайлингом Xenos и 8in16 и пишет `app/src/nier_switch_prompts_data.h`.

Отвергнуто: подмена текстуры по хэшу в нашем рендерере (только нативный рендерер, тексты всё равно нужны);
изменение файлов игры на диске (3 ГБ архивы, файлы пользователя); перехват функций игры, как в masseffect-nx
(нужен разбор кода игры, итог для игрока тот же).

## Проверка

Мак: скриншоты подсказки «Controls» в начале боя (иконки X и LT), титульного экрана, подсказки пропуска
катсцены, окна с картой; тесты кодировщика (кодирование → декодирование) и наложения кусков на чтение.
Консоль: тот же путь после залива сборки.
