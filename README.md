# nier-nx

Static recompilation of NieR (Xbox 360, 2010, title ID 535107E8) with ReXGlue: macOS first, then Nintendo Switch.

No game data is part of this repository. You need your own disc dump of `Nier (USA, Europe) (En,Ja,Fr,De)`;
`app/game.lock` lists the hashes the port is built against.

Design: `docs/superpowers/specs/2026-11-17-nier-nx-port-design.md`.
